# 🌐 Swarajya Staging Automation - Shared Core Framework & Test Data

> **Branch:** `shared`  
> **Master Repository:** [Switch to main branch](https://github.com/himanshu-prakash-test/swarajya-stg-automation/tree/main)

This branch contains the **centralized shared architecture** and **universal test data workbooks** for the Swarajya automation framework.

## 📁 Repository Structure on this Branch
```
swarajya-stg-automation/
└── shared/
    ├── config/           # Central selectors and constants
    ├── pages/            # BasePage, LoginPage, and shared Page Objects
    ├── reporter/         # Standalone and Pytest HTML report generators
    ├── test_data/        # Universal test workbooks (Swarajya-test-cases.xlsx, Swarajya-test-data.xlsx)
    └── utils/            # Excel loaders, Base URL resolvers, and thread-safe loggers
```
