# 📊 Shared Reporter Module

This directory contains universal test reporting components, HTML summary generators, and session result hooks for the **Swarajya ERP Test Automation Suite**.

## Components
- `html_reporter.py`: Custom HTML test report generator with test execution logs, timings, and screenshots.
- `hooks.py`: Pytest session-level hooks for tracking test results and status writeback.
- `models.py`: Data models and dataclasses for test execution results.
- `template.py`: HTML report rendering templates.
- `assets/`: Styling and iconography assets for reports.
