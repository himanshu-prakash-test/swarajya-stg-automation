# 📁 Shared Test Data Module

Central test data repository for the **Swarajya ERP Test Automation Suite**.

## Contents
- `Swarajya-test-cases.xlsx`: Master test suite workbook containing test cases, step definitions, and dynamic writeback results (`PASS`, `FAIL`, `SKIP`).
- `Swarajya-test-data.xlsx`: Dynamic test data sets, credentials, input records, and environment configurations across all modules.
- `auth_state_swarajya-stg_corecotechnologies_com.json`: Cached Playwright browser authentication session state.
- `sample_po.pdf`: Sample PDF document asset used for purchase order and document upload workflows.
