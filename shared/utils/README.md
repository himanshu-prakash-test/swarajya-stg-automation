# 🛠️ Shared Utilities Module

Core utility functions and helper modules for the **Swarajya ERP Test Automation Suite**.

## Components
- `excel_base.py`: Low-level Excel parser, credential resolver, and cell update engine built with OpenPyXL.
- `excel_loader.py`: High-level data loader with type casting and sheet lookup utilities.
- `paths.py`: Cross-platform absolute project path resolver.
- `popup.py`: Non-blocking desktop execution summary notification generator.
- `logger.py`: Standardized formatted console and file logger.
